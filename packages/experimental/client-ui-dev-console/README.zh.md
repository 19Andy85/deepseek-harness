# @deepseek-ai/dsh-experimental-client-ui-dev-console

[English](README.md) | 中文

## 概述

本页面贡献一个全局主面板 **项目控制台** 及其侧栏入口。它是按工作区划分的实时任务总览的浏览器面：通过 `sessionTasks` Remote 读取所选工作区，列出每个活跃会话及其仍在运行的活动家族，并在会话模型上报状态或活动变化时重新读取。本包需要选择启用，不产生面向模型的贡献。

<a id="use-this-package"></a>
## 使用本包

在同时挂载了提供 `sessionTasks` Remote 的 Host 控制器的 Web 组合中挂载本页面；侧栏入口会为当前工作区打开该面板。本包不声明配置。

### 页面能做什么

- 贡献 `project-console` 主面板及其侧栏入口，并带有八种客户端语言的文案。
- 选择一个工作区，读取其活跃会话；每行给出会话标题（缺失时回退为「未命名会话」）、`running` 或 `idle` 状态、最近一次人类提示的相对时间、工作目录，以及仍在运行的活动家族；页头用按比例分段的项目状态条与图例呈现健康度（运行中、需要你、失败、已完成未读、空闲），点击分段可筛选列表。空白占位会话不显示，空闲且没有标题、提示或活动的会话也不显示；行按「运行中优先、其次最近提示时间」排序，每行带状态色条与活动轨道（对话轮次、后台作业、子代理、定时任务）及条目；知道时间时显示该活动已运行多久，运行中但带时间的活动超过 Host 阈值无变化时显示 **停滞**。面板可见时除事件触发外还会每隔几秒自动重读，**刷新** 按钮可立即读取。
- 从侧栏入口打开控制台，或从工作区行的"…"菜单打开：该行工作区会成为选中范围。
- 两种视图上方的 **关系图** 以节点与曲线连线画出每个可见父会话及其派生会话（含已结束的子代理），可折叠，带状态点与打开动作；带有持久化派生会话的会话同时显示 **子代理 N** 标签，其聚焦卡列出这些子会话并提供 **打开会话**（即使子代理已结束）；被其他会话派生的会话显示 **派生自 …**，派生方在活动轨道中列出该子代理，两者的协作关系无需打开对话即可读懂。
- 点击任意会话行在控制台内跟随该会话：页面通过 `sessionTasks.follow` 持续更新该行（标题、状态、最近时间、工作目录、运行中的活动家族），直到会话不再是活跃会话并给出提示。**返回总览** 回到列表，**打开会话** 显示其对话。
- 填写首条提示词并选择 **新建会话并发送**：控制台通过既有 `session/create` Remote 新建会话，再经 `session/prompt` 发送提示词，然后打开该会话的对话。
- 在行内回复：选择 **在此会话回复**，再选 **排队发送** 追加上一轮，或 **打断并发送** 替换正在运行的一轮（同样走 `session/prompt`）。
- 运行中的行可以 **中断**，调用既有 `session/cancel` Remote。
- 待处理交互、失败轮次与未读完成汇集在列表上方的 **需要你** 区（常驻并带空状态）：审批提供 **允许一次** / **拒绝**，单选问题与计划审阅可直接点选项按钮，未读完成提供 **查看**（打开会话即确认）；有变更摘要的轮次显示文件与增删行统计，并提供 **查看变更**（打开对话，变更卡片在对话中呈现）。
- 仍在列表中的待审批行也会显示 **待审批**、工具名与 **允许一次** / **拒绝**；决策与对话中的待审批是同一个对象。
- 有待回答问题或计划审阅的行显示第一个问题；单选问题与计划审阅可直接点选项回答（多选、自由文本或多问题时显示 **去对话处理**）。
- **Token 统计**：行内显示累计 prompt/completion tokens，抽屉内补充总计；页面可见时每 5 秒自动刷新一次。
- **余额**：侧栏底部账号上方显示 DeepSeek 钱包余额（每分钟刷新）。
- **阅读大小**：自动按显示环境推导档位（Retina 缩放 → 舒适；窄屏 → 紧凑），窗口缩放/可见性变化时重算；工具栏可手动覆盖（自动/紧凑/标准/舒适）并记住选择，字号 token 整体缩放。
- **任务卡**：添加一张小卡片，拖到画布泳道或 Studio 工位即可把该 prompt 排入对应伙伴；也可点「派给选中伙伴」；任务卡按浏览器持久化，派发成功后移除。会议桌同时列出已结束的派生会话（来自关系数据）。
- **刷新界面**：平台快捷键不可用时可用工具栏的「刷新界面」重新加载页面；工具栏显示「更新于 HH:mm」。
- **交互**：悬停泳道显示摘要；双击泳道打开对应会话；活动条目的形状区分轮次/作业/子代理/定时。
- **泳道网格**：每条泳道按身份 / 活动 / 时间 / 动作四列对齐；分段上方有 **自上次查看** 变化条列出变化伙伴；等待卡片带 **⏸ + 需要你**；派生家族按最紧急成员归段并嵌套子节点。
- **关系**：默认内联；工具栏可切到画布，画布支持可见深度（L2/L3）、活动摘要、父节点后台作业与「派生」标注。
- **工作室**：房间健康条、进行中 / 会议桌 / 休息区、完成托盘、经理托盘（需要你收件箱在左侧栏）、派生生位一次性入场动效，日结仍只统计真实观察事件。
- **画布泳道**：可见伙伴按 **需要你 / 进行中 / 完成未读 / 空闲** 四段分组，派生子代理嵌套在父伙伴下方，并提供 **关系：内联 / 画布** 切换（默认内联；内联时画布面板隐藏，同一关系不会重复出现）。
- 等待卡片带暂停图标与 **需要你** 标签，等待状态不再只靠颜色区分。
- **伙伴身份**：每个会话获得由标题规则化得到的伙伴名、角色色环与首字母头像，行/聚焦/关系/收件箱/工位共享；聚焦卡可重命名并保存为手动别名（按浏览器存储），无标题会话回退为 **伙伴 · id4** 而不是裸 id。
- **全局收件箱**：页头按钮（或 **g**）打开跨工作区面板，按工作区列出所有待处理会话，支持允许/拒绝、回答选项与打开会话；Esc 或 **g** 关闭。跨工作区行显示会话 id 前缀（客户端状态映射不含标题），失败处理仍留在各工作区视图内。
- 长问题文本最多两行并在悬停时显示全文；活动类型改用统一的内联图标（对话轮次、后台作业、子代理、定时任务）；可见会话超过 12 个时切换为紧凑密度（隐藏路径与活动年龄）。
- 键盘操作：**j/k**（或方向键）移动选中，**Enter** 聚焦选中会话，**a** 批准其待审批，**r** 打开回复输入，**i** 中断其运行中轮次，**Esc** 退出聚焦/编辑；提示位于视图切换旁，窄窗口下隐藏。
- 其他工作区有会话需要处理时，正文上方会出现提示，列出各工作区及数量，并支持一键切换过去，避免按工作区限定的视图隐藏范围外的待办。
- 工作室底部显示 **今日工作室**：仅统计本控制台今天实际观察到的新会话、完成、派发、中断、批准与回答次数，并提供重置；同时明确声明不推断结果。
- 动效由真实状态驱动且克制：会话运行中工位灯呼吸，等待你的灯呼吸，刚完成的工位一次性闪亮，注意力卡片与时间线条目入场淡入；`prefers-reduced-motion` 下全部关闭。
- 工具栏可在 **画布** 与 **工作室** 之间切换，选择会被本地记住。工作室为每个可见会话显示一个工位（状态灯、头像、活动轨道、最近提示时间），点击工位即在控制台内跟随该会话。
- 会话状态或活动事件后自动重读，并把连续事件合并为一次读取；**刷新** 按钮按需读取。
- 聚焦某个会话时，该行来自跟随流，并显示 **开始观察后的变化** 时间线（带时间与持续时长的状态/活动变化）；**中断**、**在此会话回复** 与 **打开会话** 仍可用，总览的「需要你」区在聚焦卡上方保持可见。
- 每个工作区在本地存储中记住上次查看的基线；当 Host 挂载存储域时，控制台优先使用持久的已确认基线（`snapshot` 的 `changes`/`lastSeenAt`），并在隐藏与释放时确认，因此 **新** 标记跨设备一致；未挂载存储域时回退到本地基线。
- 读取失败时保留上一次的行，并显示紧凑的重试提示；只有在从未读到数据时才显示完整错误态。

### 失败与恢复

- Remote 失败时把返回的消息显示在提示中，并保留上次成功的行。
- 未挂载控制器时同样会读取失败；修好组合后点 **重试**。
- 插件释放时，存储会停止定时器、工作区订阅与状态发布。

<a id="understand-the-implementation"></a>
## 理解实现

### 设计理念

全局主面板符合"每个项目一个控制台"的形态：侧栏入口选择面板，面板把读取范围限定到所选工作区，而不是把页面绑定到某个会话。页面状态集中在一个 React 之外的存储里：视图订阅身份稳定的快照，事件触发的刷新会合并，因此一串会话活动只产生一次 Remote 读取。客户端文案保留在包内字典中，切换语言时无需 Host 往返即可重渲染。

### 源码地图

- `src/index.ts`——Host 面占位；浏览器贡献通过包的 client 声明被发现。
- `src/client/index.ts`——语言注册、`main` 面板注册与 `sidebar.panellist` 入口。
- `src/client/ProjectConsoleStore.ts`——工作区选择、总览读取、失败保留与刷新合并。
- `src/client/ProjectConsolePage.tsx`——页面组件、骨架屏、提示、数据行与页头汇总。
- `src/client/ProjectConsoleMenu.tsx`——工作区行菜单入口，在该行工作区上打开控制台。
- `src/client/ProjectConsolePage.module.css`——页面样式表，全部取自主题 token。
- `src/client/locales.ts`——八种语言字典。

### 操作流程

客户端插件先注册字典、创建存储，再注册主面板与侧栏入口。存储通过 `ctx.remote.sessionTasks.snapshot` 读取所选工作区；转发来的 `api-session/status`、`api-session/activity` 事件与 `connection/reset` 把总览标记为过期，存储再把重读合并。不会向会话日志写入任何内容。

## 模型体验

无，因为本页面读取 Host Remote，并只在用户显式操作时新建会话；不产生模型上下文或会话事件。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

这些限制说明本包何时不合适或需要额外的运维注意。它们是当前的包约束，不是任务清单。

- **仅活跃会话**——本 Host 中没有活跃智能体的会话不会出现，即使持久化的任务或定时器会为它报告活动。
- **依赖 Host Remote**——页面自身没有数据通道；未挂载控制器时显示失败提示。
- **仅覆盖简单提问形态**——审批、单选问题与计划审阅可在控制台内回答；多选、自由文本与多问题请求改为打开对话。
- **下发仅新建会话**——页头表单始终新建会话；回复针对单个已有行；提示词被接受后打开新会话的对话。
- **控制台没有内建流**——聚焦进展由既有对话视图承担；控制台本身只刷新摘要行，并在会话新增/移除、状态或活动变化时重读。
- **入口为侧栏与工作区行菜单**——通过 bundle 一键启用是推迟的一步式路径；未挂载页面插件时，工作区菜单槽位不会渲染额外行。
- **尚未进入 bundle**——本包处于实验阶段，在出现实验性 bundle 之前需要显式挂载。
